# Security Policy

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability or exposed
credential. Instead, use GitHub's **Report a vulnerability** option on the
repository's Security tab to submit a private report.

Include the affected version or commit, reproduction steps, and potential
impact when possible. You should receive an initial response within seven
days.

## Supported versions

Security fixes are applied to the latest release and the `prime` branch.
